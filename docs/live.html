Read this first

This is not a doctor and gives no medical advice. It is a research demo of how a calibrated decision model selects questions. It covers six tropical febrile illnesses and will get everything else wrong.

If you are unwell, contact a qualified clinician. If you have breathlessness, chest pain, confusion, uncontrolled bleeding, or cannot keep fluids down, seek emergency care now — do not use this page.

Do not enter anything identifying. Symptom text is sent to the OpenJEV API to be processed. Enter nothing you would not put in a public forum.

Advanced — use your own API key

This demo runs on a built-in key, so you don't need one. Enter your own only if you'd prefer — it stays in this tab, goes nowhere except api.openjev.sh, and is never stored by this site. Free keys at openjev.sh.
